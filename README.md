# WizX Plants

Identify a plant with Pl@ntNet, then keep your own collection on this phone.

Open https://eagleye869.github.io/wizx-plants/ in Safari, then Share, then Add to Home Screen.

Photos, care notes, the watering schedule, and the Pl@ntNet key stay on the phone. They are not stored in this repository.

The image-based plant species identification service used, is based on the Pl@ntNet recognition API, regularly updated and accessible through the site https://my.plantnet.org/
