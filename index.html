Guide

Pl@ntNet key

Create one free account at my.plantnet.org. Open the API key page and copy the private key.

On that same page, turn on expose my API key. Under Authorized domains, add this line, then save there:

Copy only the code in the box labeled API key. It starts with 2b10. Paste that code here, where you can read it, then tap Save key. Leave Generate new API key alone until this phone says the saved code was refused.

Free limit

Pl@ntNet allows 500 identifications a day on one free account. This app counts each check and stops at 500 so the free allowance is not passed. Adding a plant by name does not use a check. You can still water plants and edit notes after the limit is reached.

How to use it

  1. Copy the API key box from the Pl@ntNet page. It starts with 2b10. Paste it above and tap Save key.
  2. On Identify, add a photo of one plant. A leaf and a flower together make a better check.
  3. Pick the name that fits, then save the plant. The photo stays on this phone.
  4. Read the care note and set how many days between waterings. Change it after you see how the soil feels.
  5. Today lists plants that are due. Tap Watered when you water them.
  6. On iPhone, open https://eagleye869.github.io/wizx-plants/ in Safari, then Share, then Add to Home Screen. After that, the plants, photos, and key stay on the phone. The computer does not have to stay on. Naming a plant still needs the internet, because that check goes to Pl@ntNet.
